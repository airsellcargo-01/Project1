# Airsell Cargo Portal

A streamlined logistics and client communication platform designed to support Airsell Cargo operations, ensuring compliance, resilience, and efficiency.

---

## 🚀 Features
- Client communication workflows with automated email notifications
- Audit-trail permissions (tiered access for staff vs partners)
- Domain and DNS management integration
- Web form troubleshooting and automation
- Structured workflow documentation for internal/external training
